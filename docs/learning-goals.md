# AegisCAN Learning Goals

## 1. Automotive and EV Systems

Understand the basic concepts of:

- Electric Vehicles (EV)
- Battery Energy Storage Systems (BESS)
- Batteries
- Battery Management Systems (BMS)
- Electronic Control Units (ECUs)

## 2. CAN Communication

Learn:

- What CAN is
- CAN bus architecture
- CAN frames
- CAN identifiers
- CAN data fields
- Communication between ECUs
- CAN message transmission

## 3. Automotive Cybersecurity

Understand:

- Why cybersecurity is important in vehicles
- CAN security vulnerabilities
- Message injection
- Message spoofing
- Denial-of-Service (DoS) attacks
- CAN flooding
- Intrusion Detection Systems (IDS)

## 4. Python and Data Analysis

Develop skills in:

- Python programming
- NumPy
- Pandas
- Data preprocessing
- Data visualization
- Basic machine learning

## 5. AegisCAN Development

Learn how to:

- Capture or work with CAN traffic
- Preprocess CAN messages
- Extract useful features
- Detect abnormal CAN traffic
- Identify potential attacks
- Visualize detection results

## 6. Engineering and Team Skills

Develop practical experience in:

- Git and GitHub
- Version control
- Project documentation
- Testing
- Debugging
- Team collaboration
- Technical communication

## 7. Final Learning Outcome

By the end of the project, the team should understand how CAN communication works, how CAN networks can be attacked, and how an intrusion detection system can be designed to identify suspicious CAN traffic.

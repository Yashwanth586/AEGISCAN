# AegisCAN Project Charter

## 1. Project Title

AegisCAN – CAN Bus Cybersecurity and Intrusion Detection System

## 2. Project Overview

AegisCAN is a cybersecurity project focused on monitoring Controller Area Network (CAN) communication in automotive and electric vehicle systems.

The system aims to analyze CAN messages and identify abnormal or potentially malicious communication.

## 3. Problem

CAN is widely used for communication between Electronic Control Units (ECUs) in vehicles.

However, traditional CAN communication has limited built-in security mechanisms. This can make the network vulnerable to attacks such as message injection, spoofing and Denial-of-Service (DoS) attacks.

A system is therefore required to monitor CAN traffic and detect suspicious activity.

## 4. Project Objective

The main objective of AegisCAN is to develop a prototype CAN intrusion detection system that can:

- Capture or process CAN traffic.
- Preprocess CAN messages.
- Extract useful features.
- Detect abnormal communication.
- Identify potential attacks.
- Display detection results clearly.

## 5. Project Scope

The project will focus on:

- Electric Vehicle (EV) systems
- Battery systems
- Battery Management Systems (BMS)
- CAN communication
- Automotive cybersecurity
- CAN traffic analysis
- Intrusion detection
- Data analysis and visualization

## 6. Major Components

1. CAN Data Capture
2. Data Preprocessing
3. Feature Extraction
4. Intrusion Detection Engine
5. Attack Detection
6. Results Visualization
7. Testing and Validation

## 7. Technologies

## 8. Expected Outcome

The expected outcome is a working prototype capable of analyzing CAN traffic and detecting abnormal or potentially malicious communication.

The system should provide understandable results that can help identify possible cybersecurity threats in a CAN network.

The first phase focuses on understanding the automotive domain, CAN communication and cybersecurity while establishing the software development environment.

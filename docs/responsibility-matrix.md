## Role Description

### Member 1 – Project / Repository Lead
- Maintain GitHub repository.
- Manage project structure.
- Coordinate project development.
- Support architecture design.

### Member 2 – CAN / Automotive Research Lead
- Study CAN communication.
- Study EV and BMS architecture.
- Research CAN vulnerabilities and attacks.
- Investigate suitable CAN datasets.

### Member 3 – Detection / Data Lead
- Work on CAN data preprocessing.
- Perform feature extraction.
- Develop detection methods.
- Support testing and validation.

### Member 4 – Documentation / Testing Lead
- Maintain technical documentation.
- Review project deliverables.
- Support testing.
- Prepare presentation and demonstration material.

## Note

Responsibilities may be adjusted during the project depending on workload, technical requirements and team progress.
